# Assurly for VS Code

> **Status: Paused** — This extension is not actively maintained. Target users scan via deployed URL, MCP, or the web dashboard instead.

Run Assurly production-readiness scans without sending source code outside your workstation.

Use **Assurly: Scan Workspace** from the Command Palette. The extension executes its bundled,
pinned CLI and writes findings to the Assurly Output channel.
