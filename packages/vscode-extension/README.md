# ShipReady for VS Code

> **Status: Paused** — This extension is not actively maintained. Target users scan via deployed URL, MCP, or the web dashboard instead.

Run ShipReady production-readiness scans without sending source code outside your workstation.

Use **ShipReady: Scan Workspace** from the Command Palette. The extension executes its bundled,
pinned CLI and writes findings to the ShipReady Output channel.
